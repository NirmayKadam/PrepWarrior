# API Reference - AI Mock Interview Platform

This document provides a comprehensive API reference for the mock interview platform, including request schemas, header parameters, response formats, and error codes.

---

## 1. Authentication & Headers

Protected endpoints (under `/api/**`) require user authentication via Firebase. Unauthenticated endpoints include `/api/newsletter`, public page routes, and H2 database console routes.

### Required Headers
- **`Authorization`**: Bearer token containing the Firebase ID Token.
  *Example:* `Authorization: Bearer eyJhbGciOiJSUzI1NiIsImtpZCI6...`
- **`Content-Type`**: Always required as `application/json` for POST endpoints (except transcription which uses `multipart/form-data`).

## 2. Interview Management API

### Create Mock Interview
Generates 5 tailored interview questions based on job description and experience.

- **URL**: `/api/interviews`
- **Method**: `POST`
- **Body**:
```json
{
  "jobPosition": "Backend Engineer",
  "jobDesc": "Develop Java APIs, Spring Boot microservices, and optimize SQL queries",
  "jobExperience": "3"
}
```
- **Response**: `201 Created`
```json
{
  "mockId": "a1b2c3d4-e5f6-7890-abcd-ef1234567890"
}
```

### Get Interview Details
Fetch the generated questions and details for a specific interview.

- **URL**: `/api/interviews/{id}`
- **Method**: `GET`
- **Response**: `200 OK`
```json
{
  "id": 1,
  "mockId": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
  "jobPosition": "Backend Engineer",
  "jobDesc": "Develop Java APIs, Spring Boot microservices, and optimize SQL queries",
  "jobExperience": "3",
  "createdBy": "john@example.com",
  "createdAt": "2026-07-11",
  "jsonMockResp": "[\n  {\n    \"Question\": \"Can you explain the difference between a Bean and a Component in Spring?\",\n    \"Answer\": \"A Bean is an object instantiated, assembled, and managed by Spring IoC...\"\n  }\n]"
}
```

### List User Interviews
Fetch all mock interviews created by the authenticated user.

- **URL**: `/api/interviews/list`
- **Method**: `GET`
- **Response**: `200 OK`
```json
[
  {
    "id": 1,
    "mockId": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
    "jobPosition": "Backend Engineer",
    "jobDesc": "Develop Java APIs...",
    "jobExperience": "3",
    "createdBy": "john@example.com",
    "createdAt": "2026-07-11",
    "jsonMockResp": "..."
  }
]
```

### Submit & Evaluate Answer
Evaluate a user's answer to an interview question using AI.

- **URL**: `/api/interviews/{id}/answer`
- **Method**: `POST`
- **Body**:
```json
{
  "question": "Can you explain the difference between a Bean and a Component in Spring?",
  "correctAns": "A Bean is an object managed by Spring IoC...",
  "userAns": "Beans are managed by Spring container and @Component tells Spring to create a bean automatically."
}
```
- **Response**: `200 OK`
```json
{
  "rating": "8",
  "feedback": "Correct base concept. You could elaborate on @Bean vs @Component definitions for a higher rating."
}
```

### Get Interview Feedback
Retrieve all recorded answers, ratings, and AI feedbacks for a given interview.

- **URL**: `/api/interviews/{id}/feedback`
- **Method**: `GET`
- **Response**: `200 OK`
```json
[
  {
    "id": 1,
    "mockIdRef": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
    "question": "Can you explain the difference between a Bean and a Component in Spring?",
    "correctAns": "...",
    "userAns": "...",
    "feedback": "...",
    "rating": "8",
    "userEmail": "john@example.com",
    "createdAt": "2026-07-11"
  }
]
```

## 4. Helper Services

### Transcribe Audio
Uploads a user audio recording and returns a text transcription using Gemini's multimodal capabilities.

- **URL**: `/api/transcribe`
- **Method**: `POST`
- **Content-Type**: `multipart/form-data`
- **Request Parameters**:
  - `audio`: File (binary upload, Max 15MB. Only audio Mimetypes allowed).
- **Response**: `200 OK`
```json
{
  "transcription": "In my previous role, I designed a microservices architecture..."
}
```

### Submit Newsletter / Contact Form
Submits a user message via the contact form. This is a public API.

- **URL**: `/api/newsletter`
- **Method**: `POST`
- **Body**:
```json
{
  "name": "Jane Doe",
  "email": "jane@example.com",
  "message": "Interested in premium enterprise custom modules."
}
```
- **Response**: `200 OK`
```json
{
  "success": true
}
```

## 5. Error Responses

The API uses a global exception handler. Uncaught and custom errors return standard JSON payloads.

```json
{
  "error": "Error details or message"
}
```

### HTTP Status Matrix
- **`400 Bad Request`**: Sent if validation checks fail (e.g., missing properties or years of experience outside constraints).
- **`401 Unauthorized`**: Sent when the Authorization header is missing or contains an invalid Firebase ID Token.
- **`403 Forbidden`**: Returned when the user lacks appropriate permissions (e.g. rate limit exceeded).
- **`404 Not Found`**: Returned if the target entity (interview, question bank) does not exist.
- **`413 Payload Too Large`**: Returned if uploaded audio file size exceeds 15MB.
- **`502 Bad Gateway`**: Returned if Gemini returns a non-parseable response format or Gemini service is unavailable.
- **`500 Internal Server Error`**: For unhandled server-side exceptions.
